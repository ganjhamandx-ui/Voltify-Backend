¿Cómo funciona esta sección?

El usuario no debe ingresar manualmente el consumo eléctrico. Voltify almacena las mediciones asociadas a cada artefacto y esta pantalla permite consultarlas. Cuando se integre completamente el sistema IoT, las nuevas lecturas se incorporarán automáticamente. El costo mostrado en cada registro corresponde únicamente al consumo de energía según la tarifa actual; el cargo fijo mensual no se reparte entre mediciones ni artefactos.
